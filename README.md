# VOSC Activity-1: Tic-Tac-Toe

**Play online:** https://pallavi-eslavath.github.io/VOSC-Activity-1/

A simple two-player Tic-Tac-Toe game built with only HTML, CSS and JavaScript.
This is my submission for the VOSC Activity 1 prerequisite task.

## Features
- **Two modes:** play with a friend (2 Players) or play against the computer
- **Two difficulty levels:** Easy (random moves) and Unbeatable (uses the minimax algorithm)
- Detects wins (rows, columns, diagonals) and draws, and highlights the winning line
- Scoreboard for X, O and draws, saved in the browser so it survives a refresh
- The starting player alternates every round
- "New round" and "Reset scores" buttons
- Responsive layout that works on phones, tablets and desktops

## How to run
1. Download or clone this repository.
2. Open `index.html` in any web browser (double-click it).

No installation or server is needed.

## How to play
1. Player X goes first. Click an empty square to place your mark.
2. Players alternate turns.
3. The first player to get three marks in a row (horizontal, vertical or diagonal) wins.
4. If all nine squares are filled with no winner, the game is a draw.
5. Click **New round** to play again, or **Reset scores** to start fresh.
6. Choose **vs Computer** at the top to play alone. You are X and the computer is O. Pick **Easy** or **Unbeatable**.

Switching mode or difficulty resets the scores.
